## 📖 প্রজেক্ট সম্পর্কে

BAFI Topup হলো বাংলাদেশের গেমারদের জন্য একটি আধুনিক গেমিং টপ-আপ প্ল্যাটফর্ম, যেখানে সেকেন্ডেই যেকোনো গেমের টপ-আপ করা যায়।

---

## ✨ মূল ফিচারসমূহ

- 🔐 **নিরাপদ Authentication** — Supabase দিয়ে সুরক্ষিত
- 🎮 **গেম টপ-আপ** — Free Fire, PUBG, COD সহ সব জনপ্রিয় গেম
- 💰 **মাল্টিপল পেমেন্ট** — বিকাশ, নগদ, রকেট
- 💳 **ওয়ালেট সিস্টেম** — টাকা জমা ও উত্তোলন
- 📦 **অর্ডার ট্র্যাকিং** — রিয়েল-টাইম অর্ডার স্ট্যাটাস
- ⭐ **রিভিউ ও রেটিং** — ইউজার ফিডব্যাক
- ❤️ **পছন্দের তালিকা** — গেম সেভ করুন
- 🎟️ **কুপন সিস্টেম** — ডিসকাউন্ট অফার
- 👥 **রেফারেল সিস্টেম** — বন্ধু আমন্ত্রণ করে আয়
- 🌐 **বহুভাষী** — বাংলা + ইংরেজি
- 🌙 **ডার্ক মোড** — Light/Dark theme
- 📱 **PWA** — মোবাইলে অ্যাপের মতো ইনস্টল
- 🔔 **Real-time Notification** — লাইভ আপডেট

## 🛠️ Tech Stack

| প্রযুক্তি | ব্যবহার |
|----------|---------|
| **React 18** | Frontend framework |
| **Vite** | Build tool |
| **Tailwind CSS** | Styling |
| **Supabase** | Database + Auth + Realtime |
| **React Router** | Routing |
| **Lucide React** | Icons |
| **Recharts** | Admin charts |
| **React Hook Form** | Form management |
